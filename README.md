## Hi, I'm Siddharth

I study how neural networks store, retrieve, and lose memories.

In the brain, learning something new can interfere with what is already stored, and the brain has ways to manage that. Language models have the same problem: changing one fact can quietly disturb others. I want to understand this at the level of weights, and use it to build AI systems that keep learning from experience without forgetting.
